## 0. 记号与公共模型

* 场地 100 m×100 m，O=(50,50)；建筑 B1–B5（表1）；车辆等效圆盘半径 R_V=1.5 m，速度 3 m/s，
  相机位于盘心、高 2 m；云台俯仰 ∈ [−10°, 80°]，方位/俯仰最大 30°/s（同时转、取慢轴）；
  行驶期间云台保持正东水平，停车后才调转；联合观测 5 s，观测后云台回正东再出发。
* 警情 (θ, r, H) ⇒ 目标水平位置 T′=(50+r cosθ, 50+r sinθ)，三维 T=(·,·,H)。
  T1=(84.64, 70, 45)，T2=(11.03, 72.5, 35)，T3=(59.83, 13.29, 55)。
* **站点可行性三约束**（`swb_common.feasibility_mask`，向量化实现）：
  1. 车辆几何：1.5 ≤ x,y ≤ 98.5，且圆盘不侵入建筑（到建筑矩形距离 ≥ 1.5）；
  2. 视线无遮挡：相机→目标线段与任一棱柱（3D slab 检验）相交即为遮挡（相切算遮挡）；
  3. 仰角：−10° ≤ el = atan2(H−2, d) ≤ 80°。
  由 3 得最短水平距离 r_min = (H−2)/tan80°（T1: 7.58 m，T2: 5.82 m，T3: 9.35 m）。
* **绕障行驶**：建筑外扩 1.5 m 后建可视图（外扩矩形角点为节点，Floyd–Warshall 预计算），
  任意两点最短路长 = 直连（若互视）或 经可视节点进入路网（`PathPlanner.dist`，带缓存）。

## 1. 问题1 — 单目标可观测域与最优站

**模型** 可行域 Ω = {s : C1∧C2∧C3}；质量度量 Q(s)=1/r(s)，r 为相机到目标的水平距离。
"最优"= argmax Q ⟺ argmin r。由于 el ≤ 80° 强制 r ≥ r_min = 43/tan80° = **7.5821 m**，
故 Q* = 1/7.5821 = **0.1319 m⁻¹**，且最优必在 r_min 圆上取得。

**结果**（results/problem1_results.json）
* 可观测域占场地 59.9%（0.5 m 网格）；建筑后侧出现遮挡阴影带，r_min 圆内侧为仰角禁区。
* r_min 圆上的可行弧为连续集合 → **平局决胜规则**（论文需明示）：
  (T1) 距调度中心 O 最近；(T2) 方位角（自东逆时针）最小。
  选出最优站 **(80.50, 63.65)**（在 B2 外扩边界切点处），r=7.5821 m，仰角恰 80°，距 O 33.4 m。

## 2. 问题2(1) — 双站交会精度模型与 T2 最优双站

**精度模型** 站 i 的测角 θi = θi° + εi，εi ~ N(0,(1°)²) 独立。对交会点线性化
（设 u_i 为站 i→目标的单位向量，d_i 为水平距离，γ 为两视线夹角），可得解析式

  **δP = ( d1·ε1·u2 − d2·ε2·u1 ) / sin γ**，
  协方差 C = σ²/sin²γ · (d1² u2u2ᵀ + d2² u1u1ᵀ)，非奇异 ⟺ sin γ ≠ 0。

**精度指标** σ_RMS = √tr(C) = σ·√(d1²+d2²)/|sin γ|（水平均方根位置误差，m）。
合理性：tr C = E‖δP‖² 与坐标旋转无关、是标准 GDOP 型指标，且显式揭示两种退化
（γ→0/180° 与远距离）。另报 CEP50（蒙特卡洛中位径向误差）。

**优化** min σ_RMS s.t. 双站均在 T2 可观测域、所选两车绕障行驶时间 ≤ 30 s。
解析下界：d_i ≥ 5.82、|sin γ| ≤ 1 ⇒ σ_RMS ≥ √2·σ·r_min = **0.1436 m**，
当且仅当双站同在 r_min 圆且 γ=90° 时取得（T2 在 B3 正上方，东侧/南侧近距被 B3 遮挡，
可行弧位于西北象限）。Nelder–Mead 多起点数值优化验证无更优解。

**结果**（V3+V5，平局决胜：总行驶时间最短 → 中点距 O 最近 → 字典序）
* V3 → 站 (6.00, 75.44)，行驶 4.42 s；V5 → 站 (13.96, 77.52)，行驶 13.07 s；
* 基线长 B=8.23 m，γ=90.0°，d1=d2=5.82 m，**σ_RMS=0.1436 m**，CEP50=0.119 m；
* 蒙特卡洛（精确测角+直线交会，2×10⁵ 次）CEP50=0.1197 m，与解析 Rayleigh 理论 0.1197 m 吻合。

**退化讨论**：γ→0°/180° 时 sin γ→0，C 发散（两视线近平行/共线，交点病态）——
实践中限制 γ∈[30°,150°]；站位于可观测域边界（仰角恰 80°）时：几何上仍良态（γ=90°），
但测量模型假设退化（近场、车辆圆盘与相机高度不可忽略）、云台顶界无余量、视线相切风险↑
——建议留 2° 仰角裕度并做鲁棒化（对 ±δ 扰动取 worst-case）。

## 3. 问题2(2) — 并发警情下的车辆复用与路由

**模型** 6 个任务槽（3 警情 × 2 车）、5 车 ⇒ 至少一车服务两个警情（链）。决策变量：
分配（每警情两辆不同车）× 各车任务顺序 × 每任务站址（∈对应可观测域）。
时间轴规则（`swb_common.simulate`，不动点迭代求联合开始时刻）：

  travel → slew = max(|Δpan|,|Δtilt|)/30 → 等待 → 观测 5 s（start = max 两车 ready）
  → reset = max(|pan|,|tilt|)/30 → 下一任务出发。

**目标** min max_a start_a。

**算法**（`sched_optimize`）：分配全枚举（C(5,2)³=1000 组合 × 链内排序，剪枝 max_tasks=2）
→ 行驶下界预排序 → 前 150 个精确仿真 → 前 8 个做站址坐标下降局部搜索（Top-10 邻域）。
关键建模自由度：**车辆可在原位观测**（站址=初始位置，只需云台调转），
远距站（如 V3 对 T3，r≈86 m）同样合法——这是大幅压缩 makespan 的关键。

**结果**（results/problem2_2_results.json，甘特图 fig_p2_2_gantt.png）
* **优化方案**：V1→T2（原位），V2→T3（原位），V4→T2（B2 北侧站 (87.85,72.5)），
  V3→[T1, T3]（复用链），V5→T1（原位）；观测开始 **T1=2.39 s，T2=7.50 s，T3=10.65 s**，
  **max = 10.65 s**。
* **最近assign启发式**（基线，独立定义）：警情按标号顺序，各警情取"乐观最早就绪"的两辆车，
  允许追加链 → max = **21.09 s**（V1 被链到 T2→T3，V2/V4 闲置；其乐观时序忽略伙伴等待，
  真实 T3 被拖到 21.09 s）。
* **差异来源**：①启发式逐警情贪心、无链协调 → 强车被过度复用、近车闲置；
  ②启发式用自身就绪时间当观测开始（忽略伙伴），系统性低估下游延误；
  ③优化模型把"复用链的位置"与"站址选择"（含原位观测与平差转角）联合优化。

## 4. 问题3 — 定位与指向误差对水平测角的影响

**传播模型** 真位置 P，估计 P̂=P+δ，δ=(δx,δy)~N(0,σ_L²) iid，σ_L(s)=0.3+0.02s；
指令方位 ψ_cmd = bearing(P̂→T)（按**估计位置**指向），真方位 ψ_true = bearing(P→T)，
Δψ = wrap(ψ_cmd−ψ_true)。目标已知、水平距离 d=40 m 固定。

* 关键引理：δ 为各向同性高斯 ⇒ 其在视线法向的投影 e_⊥ ~ N(0, σ_L) **严格成立**；
  Δψ = atan(e_⊥/d)·R2D + ε_z + ε_c，ε_z~N(0,0.8²)、ε_c~N(0,0.6²) 独立。
* 小角线性化：Δψ ≈ N(0, σ_tot²)，**σ_tot(s) = √( (σ_L(s)/d·R2D)² + 0.8² + 0.6² )**。
* 近似有效性：σ_L/d ≤ 4%（s* 处），atan 与线性差 <0.1%；wrap 不激活（σ_tot≈2.6°≪180°）。

**求解** P(|Δψ|≤5°)≥0.95 ⟺ 5° ≥ z₀.₉₇₅·σ_tot(s)（z=1.959964）
⇒ σ_L ≤ d/R2D·√((5/z)²−0.8²−0.6²) = **1.6384 m** ⇒ **s* = (1.6384−0.3)/0.02 ≈ 66.9 m**。

**80 m 处仍需满足** ⇒ σ(80)=a+80b ≤ 1.6384 m（a,b≥0）：
a∈[0, 1.6384] m，b∈[0, 0.02048] m/m，等价约束 **a + 80b ≤ 1.6384**。

**验证与贡献分解**（results/problem3_results.json，fig_p3_error.png）
* 蒙特卡洛（精确几何+wrap，4×10⁵ 次/点）：解析 vs 仿真最大偏差 0.02 个百分点；
  s* 处精确 atan 模型 P=0.9506 vs 解析 0.9500（线性化略保守，安全）。
* 方差贡献：定位 (σ_L/40·R2D)²、零偏 0.64°²、控制 0.36°²。
  s=0：15.6%/54.0%/30.4%；**s≈20 m 起定位误差占比 >50%**；s=66.9：84.7%/9.8%/5.5%。
* 部署启示：短距机动优先标定云台零偏；累计行驶 >20 m 后里程计/定位漂移主导——
  限制单次机动距离或途中重定位（与 s*≈67 m 的硬约束一致）。

## 5. 问题4 — 扰动重调度与方案比较

**规则实现**（problem4.py）
* 扰动于 t=5 发生：新警情 T4(θ,R,50)；5 车等概率失效 1 辆；通信中断 [5,t_rec]，
  中断期间车辆继续执行在手任务，恢复后才接受新指令。
* "扰动前已开始的观测视为完成"：基线中 T1 于 2.39 s 开始 → 任何场景下 T1 都算完成，
  V3/V5 锁定至观测结束+回正（≈8.4/8.9 s）；未开始观测的被派车辆可改派
  （途中车在其插值位置可用、云台按当前指令姿态近似；等待车已指向、立即可改派）。
* KEEP：无论扰动如何，执行 t=0 原计划（失效车的链停滞，其警情无法观测，T4 永不观测）。
* RES：事件触发重优化——在决策时刻（无中断 t=5；有中断 t_rec）冻结状态，
  以与 2(2) 相同的枚举+仿真+局部搜索对"未完成警情(∪T4)"重调度，
  对"保留被打断任务"的车辆精确计入已完成的调转（commit 机制）。

**评估** 窗口 [0,60] s：η=k/N，t_last（有警情无法开始则记 60），字典序 (η↓, t_last↑)。

**场景设计**（合理性论证见论文）
* NA：θ∈{0°,45°,…,315°}×R∈{30,50} 共 16 个 —— 45° 步长覆盖相对建筑布局的所有来向，
  R 取允许区间两端；
* FA：V1–V5 各 1 个（穷举等概率失效源）；
* CO：t_rec∈{10,20,30}（早/中/晚恢复）；
* 组合：NA(θ∈{0°,180°},R=40)×FA(5) = 10，FA×CO(20) = 5，NA(4 方向)×CO(20) = 4，
  三重扰动 2 个 —— 共 **45 个场景**。

**结果汇总**（results/problem4_results.json，fig_p4_comparison.png）
| 扰动类型 | KEEP (η, t_last) | RES (η, t_last) | 结论 |
|---|---|---|---|
| 仅新警情（16 场景） | (0.750, 60) | (1.000, 15.4–20.0) | 重调度必收益：T4 被插入且全部 ≤60 s |
| 失效 V1–V4 | (0.667, 60) | (1.000, 12.1) | 失效车的搭档警情重分配后恢复 |
| 失效 V5 | (1.000, 10.65) | (1.000, 10.65) | **无收益**：其观测已于 2.39 s 开始（完成），链未被打断 |
| 仅中断 | (1.000, 10.65) | (1.000, 10.3–10.65) | **几乎无差异**：t=0 已下达全部指令，中断不破坏原计划 |
| NA+FA | (0.500–0.750, 60) | (1.000, 17.8–25.2) | 收益最大（η +0.25–0.5） |
| FA+CO | (0.667–1.000, 60) | (1.000, 10.7–23.5) | 恢复后重排，η 恢复至 1 |
| NA+CO | (0.750, 60) | (1.000, 22.5–23.5) | T4 在恢复后 ~12 s 内插入 |
| 三重 | (0.500, 60) | (1.000, 22.9–24.7) | 组合扰动下 RES 仍全完成 |

**何时有效/失效的分析**
* RES 显著收益的三种机理：①新警情（KEEP 结构上不可能观测 T4，η 上限 0.75）；
  ②失效车是"未完成观测任务"的在册成员（其警情在 KEEP 下必然失败，η≤0.667）；
  ③组合扰动（延误叠加，η 掉至 0.5）。
* RES 无收益/几乎无收益：失效车的观测已在 t=5 前开始（规则判定完成，链完好）；
  纯通信中断（无新指令需求时中断本身不产生任何重排需求）。此时 RES ≈ KEEP
  （重优化只是复算同一/邻近方案），说明**重调度应事件触发而非周期触发**。
