## 4. 第二轮：验算队员给出的行程

新增 [候选路线验算器](../B题代码/route_audit.py)。它读取队员给出的二维折线，核验每个线段与场界、建筑的最小净距，并检查起终点和可选的行驶时间上限。建筑净距对整段计算，能发现“两端合法，中途切进净距带”的情况。它不生成路线、观测站或调度，也不改写原寻路模块。

在 `D:\数维杯\B题代码` 运行，下面两个输入均为回归样例：

```powershell
'[[20.8,14.8],[20,14]]' | python -X utf8 -B route_audit.py - --max-seconds 30 --start 20.8 14.8 --end 20 14
'[[20.5,16],[22,14.5]]' | python -X utf8 -B route_audit.py -
python -X utf8 -B test_route_audit.py -v
```

用自己的折线路径替换样例即可，或把坐标数组存成 UTF-8 JSON 文件，传入文件路径。结果中 `segments` 按路线顺序报告各段的建筑净距和最近建筑；`travel_seconds` 只含以 3 m/s 行驶的时间。返回码 0 表示所给折线通过，1 表示至少一项规则不通过，2 表示输入错误。圆弧等非折线路径需用相应几何复核；折线通过不代表原曲线路径、双站定位或调度也通过。

| 将队员结果送验时 | 看哪些证据 |
|---|---|
| Q1 静态站点 | 站点坐标、净距、俯仰角和视线判定；若宣称有等值最优站，说明等值条件和破平依据。 |
| Q2 车站与时间轴 | 给出每辆车的完整路点及起终点，Q2(1) 单独检查 30 s 行驶预算；另核对站对几何、两车准备时刻和复位后出发时刻。 |
| Q3 误差结果 | 给出参数和单位、解析与数值结果，以及验证误差；注明可靠性指标适用条件。 |
| Q4 场景与结论 | 给出扰动发生及通信恢复时刻、锁定任务、两策略的时间轴及指标；逐项对应比较结论。 |
