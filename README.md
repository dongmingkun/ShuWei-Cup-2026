## 核心结论速览

- 摘要 = 背景 + 逐问「方法链 + 具体数字结果」（≥5 个数字）+ 创新点 + 关键词
- 每问闭环：分析 → 建模 → 算法 → 结果；后问复用/修正前问模型
- 检验三板斧：灵敏度分析（龙卷风图）+ MAE/RMSE/MAPE + 基线对比
- 红线：AIGC >30% 取消资格；AI 使用三处标注 + 使用报告；正文 ≤25 页；全文匿名
